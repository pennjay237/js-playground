#  JavaScript Projects: API & DOM Fundamentals

This repository contains various mini-projects developed as part of a JavaScript tutorial series, focusing on core concepts like **DOM manipulation** and **asynchronous data fetching** using the `fetch` API.

---

##  Projects Overview

| Project | Key Focus | Description |
| :--- | :--- | :--- |
| **News API Fetch** | **`fetch` API**, **APIs** | Applying the `fetch` API to retrieve and display news data from a public **News API**. |
| **Quote Generator** | **`fetch` API**, **Arrays** | Uses `fetch` to load an array of quotes and initially displays the **first quote** from the fetched data. |
| **Random Quote by Category** | **`fetch` API**, **Logic** | Extends the Quote Generator to **fetch and display a random quote** based on a user-chosen **category**. |
| **Project 3: DOM Manipulation** | **DOM** | A general project focused on interactive manipulation of the Document Object Model. |
| **Hex Color Picker** | **`Math.random`**, **Styling** | Implements logic using **`Math.random`** to pick a random **hex color code** and applies it dynamically to a UI element (a box). |
| **Project 4: UI Development** | **DOM Initialization**, **CSS** | Initial setup and styling of a user interface, including **initializing DOM elements** for interaction. |

---

##  Key Technologies & Concepts

* **JavaScript (ES6+)**: Core programming language.
* **`fetch` API**: Used for making **HTTP requests** and handling responses (e.g., retrieving data from the News API).
* **DOM Manipulation**: Changing the content, structure, and style of a web page.
* **`Math.random()`**: Used for generating random values (e.g., for hex color picking).
* **HTML & CSS**: For structure and styling.
